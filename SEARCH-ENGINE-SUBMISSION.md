## Step 1: Google Search Console

### Verification Options

You need to verify ownership of paidproperly.co.za. Pick the easiest method:

#### Option A: HTML File Upload (Easiest for GitHub Pages)
1. Go to: https://search.google.com/search-console
2. Click "Add Property" → Enter `paidproperly.co.za`
3. Google will give you an HTML file to download
4. Upload it to your GitHub repo root
5. Push to GitHub
6. Click "Verify" in Search Console

#### Option B: DNS Verification
1. Google gives you a TXT record
2. Add it to your DNS (same place you set up the domain)
3. Wait 10 minutes for propagation
4. Click "Verify"

#### Option C: HTML Meta Tag
1. Google gives you a meta tag like: `<meta name="google-site-verification" content="xxx" />`
2. I'll add it to the `<head>` section of index.html
3. Push to GitHub
4. Click "Verify"
