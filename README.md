# PaidProperly

**Get paid properly for remote work in South Africa** 🇿🇦💰

Tools, guides, and resources for South Africans earning USD from remote work.

## Live Site

👉 **https://paidproperly.co.za**

## Features

### 🧮 USD Salary Calculator
Convert USD remote work salary to ZAR take-home pay. Includes:
- 2026 SARS tax calculations (exact brackets + rebates)
- Live USD/ZAR exchange rates
- Employee vs Freelancer comparison
- UIF, medical aid, and retirement annuity deductions
- VAT registration threshold alerts
- Provisional tax estimates

### 📚 Tax & Legal Guides
- Complete freelancer registration guide (SARS, VAT, provisional tax)
- Getting paid in USD (payment platforms comparison)
- Working remotely for international companies

## Tech Stack

- **Frontend:** Vanilla HTML/CSS/JavaScript
- **Hosting:** GitHub Pages
- **Domain:** paidproperly.co.za
- **Exchange Rates:** exchangerate-api.com (free tier)

## Local Development

1. Clone the repo
2. Open `index.html` in a browser
3. Calculator works offline (fetches live rates when online)

## Deployment

Automatic via GitHub Pages on push to `main` branch.
